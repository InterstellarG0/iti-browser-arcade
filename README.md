# ITI Browser Arcade

[A free browser-game catalog by Interstellar Gaming](https://interstellarg0.github.io/iti-browser-arcade/), built for the Kit 001 picnic-table ThinkPad and visitors using their own devices. Interstellar Ants is the featured ITI original. The 25 links supplied from the viral post are tracked in `index.html`. External games remain on their respective sites.

## Brand colors

ITI business rule #2 applies to the arcade and its artwork. Use the established black (#0c0c0e), red (#ff7779), and gold (#f4c76d) palette from ITI Trading Foundry. Card images are original illustrations inspired by each game's setting.

## Link status

- **Game page found** means the destination appears to be the advertised game or browser port. It can still require game files, a sizable browser download or particular hardware.
- **Bring your own game files** appears after the main game listings and includes full Diablo plus both Halo ports. Diablo shareware remains in the main list because it starts without personal game files.
- **Under review** keeps the supplied URL in the source without a public launch button. Keep redirect chains and title mismatches under review until resolved.
- A successful field test reaches playable input without a launcher. Verify controller, touch, local two-player and online multiplayer independently. Record relevant game-file requirements and use terms before putting an external game on the Kit 001 quick-play shortlist.

## Improvement loop

1. Review the original links, GitHub issues and new candidates. Confirm destination identity and setup on the browser before promoting a link.
2. On the ThinkPad, use a consistent browser and network setup. Record launch attempts, seconds to first playable input, and known input or local two-player results in the page’s **Kit 001 playtest log**. Use the site revision to distinguish before and after measurements.
3. Compare the success bars, sample counts and median time to play by revision. Use fresh loads when measuring launch friction. For online and shared play, test separately with two devices or two controllers as appropriate.
4. Make one focused change, record the reason in the commit or issue, and repeat the same test. Share aggregate results through an issue or pull request where useful.

The log stays in the browser that recorded it, with CSV export for comparisons across devices. No central telemetry is configured. External games require internet access and may have independent terms and data practices.

To preview the static site, open `index.html` in a browser. GitHub Pages serves it from the root of `main`.
